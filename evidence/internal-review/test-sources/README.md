# Archived test source

These are exact copies of the additional contract VM test sources and existing
regression suite reviewed/executed in the original workspace. Their existing
relative imports and external fixtures are intentionally preserved. They are
evidence attachments, not standalone commands runnable from this directory.
See the parent audit reports for original paths and commands. The full broader
operations harness is not bundled here. The repository's normal `tests/` directory
is the self-contained 27-case adapter suite; do not confuse its count with the
121-case combined audit evidence.
