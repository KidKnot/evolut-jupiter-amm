# Dependency advisory triage — 29 October 2026

This is a public advisory inventory and limited call-site/target triage, not a clean `cargo audit` certification or proof that every transitive path is safe. The audit queried OSV with public crate names/versions only and saved its raw response in `dependency-advisories.json`. 704 unique registry package versions produced 22 package-version matches / 21 advisory IDs; aliases overlap.

The two lockfiles are different dependency universes. The contract root lock describes the deployed build; the adapter resolves vendored source under the adapter root lock. `cargo tree --edges normal` was captured using the installed Solana compiler with `--target sbf-solana-solana` for the contract, and the host compiler for the adapter. These graphs still include normal dependencies of procedural macros; graph presence alone does not prove a crate is inside the SBF or a vulnerable function is reachable. Absent packages may be build/dev/optional dependencies retained in the lockfile.

This review did not update either lockfile. A lockfile edit cannot patch the already-deployed binary, and updating only adapter math could introduce quote/execution differences. Remediation is open and requires a separate candidate, tested artifact and normal owner-authorized upgrade.
